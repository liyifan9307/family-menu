# UI 对齐记录 · 2026-11-26

基准：schedule-preview.html、family-preview.html 与 schedule-design-addendum.md。完成代码层样式对齐，模拟器和真机视觉验收待执行。

| 页面 | 本轮调整 |
|---|---|
| 主页 | 家庭名只读，切换入口保留在“我的”；今日接送标题、条数、时间与事项、地点与负责人分层展示；点菜改为稿件中的紧凑次级卡片 |
| 日程列表 | 左侧时间栏、右侧事项和成员色点；文字状态标签；底部两个描边分享按钮与圆形新增按钮 |
| 新增/编辑 | 日期与时间并排；负责人用可换行色点胶囊；底部固定绿色保存按钮；结束时间与备注仍折叠 |
| 只读 | 绿色提示区、家庭日期标题、独立事项卡片；姓名、负责人、地点和状态保持大字；避免已完成整卡降低透明度 |
| 图片 | 绿色标题区、白色正文、分隔线、居中小程序码、生成时间及到期说明；灰绿预览背景 |
| 我的 | 标题42rpx，家庭摘要和菜单卡片圆角24rpx，与基础稿一致 |

统一处理原生 style:v2 按钮宽度、边框、默认外边距；内容保留滚动与底部安全区，不照搬静态稿固定高度和 overflow:hidden。每周重复首版继续隐藏；孩子仍为文本输入。首页不额外加入基础稿中未确认的“我的家人”模块。

验证：21项行为测试通过；8个WXML经微信本机编译器通过；WXSS编译通过；JavaScript语法、事件绑定与差异空白检查通过。电脑操作权限未授予，未观察到微信模拟器最终画面，不能把上述检查当作像素级还原验收。
