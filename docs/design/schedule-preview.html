评审对照 · 决策与视觉落点

决策确认内容视觉稿落点
Q-1入口放主页卡片图①：卡片露条数 + 首条时间；tabBar 保持两项，日程为二级页面（图②③④均无 Tab）
Q-2全员可新增图②右下角 ＋ 对所有 active 成员可见；图③表单无角色门槛
Q-3只读页 + 分享链路图②「分享给家人」→ 图④；图④全页无任何写入口，底部只有说明
Q-4只做变更即时通知视觉稿不出现定时提醒设置项；通知只在保存后触发
Q-5包含姓名 + 门牌图④「茂茂 + 详细地点」、图⑤同样完整展示；两处均加"仅转发家人 / 7 天有效"提示
Q-6统一 co_member图②成员色点沿用 MEMBER_COLORS 五色板，与「我的」页家庭成员视觉一致
⚠️ Q-5 提醒：图④⑤把孩子姓名、详细门牌、时间三项放在同一屏，信息敏感度高。评审时可确认是否保留"仅转发给家人"的文案；技术侧已用 7 天过期 token 兜底，但转发范围靠人自觉，这一点要跟实际使用者讲清楚。
