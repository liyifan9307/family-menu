优化稿变更清单

本轮设计稿相对代码现值共 6 项建议，逐条评审。通过后才会落到 wxss / wxml，代码目前未改动。

#项目代码现值优化稿建议状态
①菜单图标emoji 👥✉️⚙️assets/ui 三张 png待评审
②家庭切换按钮顺序按组件现状「＋创建家庭」primary 在前待评审
③邀请码显示默认展开 ABC234默认折叠 ••••••待评审
④圆角 / 字号卡片 40–44rpx；标题 46–48rpx卡片 24rpx；标题 42–44rpx待评审
⑤主页加「我的家人」无此模块头像 + 人数 + 邀请入口待评审
⑥家庭切换入口主页 + 我的 两处收进「我的」；主页家庭名只读待评审
Ⓐ菜单图标造型assets/ui 三张（已是扁平线性，2.3–3.6KB）借鉴 iconfont 常见造型，12 款候选中挑；导出松绿 72×72 PNG，不改 wxml待评审

关于 Ⓐ：做法是借鉴 iconfont 的图标造型（不引入它的字体/CSS 机制）——从 iconfont 常见造型里挑定 → 导出成松绿 #46765a / 72×72 PNG → 沿用 members/invite/settings 文件名替换，wxml 的 image 引用零改动，无兼容风险。推荐组合：家庭成员＝家庭群组、邀请＝人＋、设置＝齿轮；12 款候选画廊见 family-preview.html 第五节。

评审结论建议：①–④ 为纯样式/还原修正，成本极低；⑤ 需 home.js 增加一次 getFamily 调用；⑥ 需删 home 页的 family-switcher 引用与相关状态。逐条给「采纳 / 打回」即可。
