## 页面与操作

首页：默认展示下一条待办及负责人；有过期未完成事项时仍可查看。无日程显示“今天还没有安排”及新增入口；全部完成/取消显示“今天的安排已结束”。点卡片进入选定日期列表。

列表：日期左右切换并提供“回到今天”；点击条目进入详情。详情展示结束时间、备注及变更记录，按服务端 permissions 显示编辑、完成、取消、恢复待办、删除。危险操作使用确认弹窗；取消与删除文案必须区分。分享标题使用所选年月日。

表单：日期、开始时间、事项、地点、孩子姓名文本、负责人；结束时间和备注放“更多信息”。首版隐藏每周重复。负责人多于一行时换行或打开选择弹层，不横向挤压。历史地点仅展示当前家庭数据。保存中禁重复点击，失败保留草稿；冲突提示“家人已更新这条安排”，支持查看最新内容。

只读页：孩子姓名、负责人、时间、事项、地点与状态均至少18px；说明可16px。显示日期和最近更新时间。已取消事项有清晰文案，完成不使用整卡低透明度使文字难读；禁止任何写入口。失效页提供“链接已失效，请让家人重新分享”，不跳身份引导。

图片：显示完整日期、生成时间、状态、姓名、地点、负责人及二维码。“图片为生成时安排，扫码查看最新”与链接到期时间分开表达。长日程拆分编号图片，预览和保存进度对应张数。

## 必补状态

| 场景 | 展示与操作 |
|---|---|
| 首次加载 | 骨架或加载提示，不能先显示无日程 |
| 真正空列表 | 空态及新增入口；只读页仅空态 |
| 加载失败 | 错误说明和重试，有旧数据时显示更新时间 |
| 保存结果未知 | 保留内容，提示正在确认，可用同一请求重试 |
| 字段错误 | 字段下具体说明，定位到首个错误 |
| 无操作权限 | 刷新条目与可用按钮，保留其他合法页面内容 |
| 家庭权限失效 | 清空家庭数据，刷新身份并选择其他家庭或进入引导 |
| 负责人离开 | “负责人已离开，请重新安排” |
| 通知失败 | “已保存，部分家人未收到通知，可分享安排” |
| 相册拒绝授权 | 提供设置入口和返回预览，用户取消不报保存成功 |
| 分享生成失败 | 显示重试，未准备好前禁用转发 |
| 解散处理中 | 明确正在清理，失败可重试，不展示已解散成功 |

## 视觉与适配

延续松绿 #46765a、暖白 #f7f7f2；业务卡片统一12px（24rpx），输入与按钮7px（14rpx），药丸标签保持圆形。不将手机外框圆角当作业务组件规范。原家庭基础页待评审的其他优化不因本说明自动采纳。

常规正文16px，关键信息不低于16px；老人页按上述18px标准。交互区域至少44×44px，日期箭头需扩大命中区。状态同时使用文字和颜色，不依赖色点区分负责人。

内容区可滚动，固定底栏预留自身高度与设备底部安全区；键盘弹起时当前输入和保存操作可达。检验320/375/430px宽度、长家庭名、30字事项、50字地点、10条以上日程、多成员、最大系统字体和断网恢复。静态稿的 overflow:hidden 不能直接复制为页面内容滚动规则。
